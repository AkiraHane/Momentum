## 功能

### 核心机制

模组在机动模式开启时覆盖玩家的地面/空中阻力、加速度和速度上限。所有数值修改使用可组合的效果系统，按优先级顺序生效。每个动作在服务端和客户端配置中均有独立开关，需两处同时启用才激活。

- **减小空气阻力**：将原版硬编码的 `0.91` 空气阻力系数替换为可配置值。
- **跳跃提升缩放**：疾跑跳跃的横向速度随跳跃提升效果等级缩放，有可配置的速度上限。
- **动态水中阻力**：水中移动速度根据玩家碰撞箱与水体的没入比例动态调整——身体露出越多，阻力越接近空气阻力。
- **自动下坡**：玩家在地面且水平移动指向下坡方向时，自动走下坡。有效下坡高度 = 原版自动上台阶高度 + 水平速度分量。在液体中和已触发上坡时禁用。
- **梯子加速**：在梯子上按住疾跑键可倍增纵向攀爬速度。

### 动作系统

模组每 tick 评估 **17 个移动状态**，进入优先级最高的匹配状态。每个状态定义各自的进入条件、每 tick 行为和退出清理。

#### 地面

| 状态 | 触发方式 | 行为 |
|---|---|---|
| **滑铲 (Slide)** | 地面移速高于阈值时按降低重心键（`C`） | 以降低的摩擦力滑行。下坡时沿检测到的坡度方向加速。退出时若前进速度大于下落速度可衔接下一段滑铲。 |
| **匍匐 (Prone)** | 地面按住 `C`，或处于游泳姿态且空间不足以蹲下 | 强制使用游泳姿态，可穿过 1 格高通道。身体旋转跟随水平移动方向。 |
| **行走 (Walk)** | 着地，无更高优先级状态匹配 | 应用模组的地面物理（自定义摩擦力、加速度、速度上限）。 |

#### 空中

| 状态 | 触发方式 | 行为 |
|---|---|---|
| **空中 (Airborne)** | 离地，无墙壁或水体状态匹配 | 空中移动控制，带模组加速度、阻力和水平速度上限。追踪每 tick 速度供动画和 MoLang 绑定使用。 |
| **准备受身 (Break Fall Ready)** | 下落速度高于阈值且按住 `C` | 预备姿态，动画跟踪下落速度。落地时转为受身。 |
| **受身 (Break Fall)** | 以降低重心姿态（滑铲/匍匐/准备受身）承受摔落伤害 | 翻滚减免摔落伤害。退出时若前进速度大于下落速度则衔接滑铲。装备喷气助推器时进一步减伤。 |

#### 墙壁

| 状态 | 触发方式 | 行为 |
|---|---|---|
| **滑墙 (Wall Slide)** | 空中贴墙并向墙方向移动 | 沿墙壁减缓下落速度，落地后减少摔落伤害。 |
| **挂墙 (Wall Hang)** | 下落时处于墙壁边缘或凹槽检测范围 | 悬挂在墙壁边缘。悬挂中可左右观察和横向移动；身体旋转被限制。 |
| **爬墙 (Wall Climb)** | 贴墙 + 向墙方向移动 + 按住跳跃键 | 沿墙壁向上攀爬，爬升高度受跳跃强度影响。喷气助推器保证最低向上速度。 |
| **蹬墙跳 (Wall Kick)** | 空中靠近墙体且墙跳冷却已就绪 | 将玩家向墙外方向弹出固定水平距离，有冷却时间。 |
| **墙跑 (Wall Run)** | 沿墙方向水平移速高于阈值 + 按住上方向键 | 沿墙面奔跑，身体朝向墙面。喷气助推器施加向上速度以对抗重力。 |
| **翻越 (Vault Up)** | 悬挂在墙壁边缘时按跳跃键 | 将玩家拉上平台边缘。 |
| **翻入 (Vault In)** | 站立或悬挂时面对 1 格高通道；站立时按 `上` + `C`，悬挂时按 `C` + `跳跃` | 以游泳姿态钻入通道。 |

#### 水体

| 状态 | 触发方式 | 行为 |
|---|---|---|
| **游泳 (Swim)** | 水下疾跑 + 按住上方向键，或水面按住 `C` + 上方向键 | 原版游泳，使用模组调整后的水中阻力。 |
| **水中推进 (Swim Dash)** | 水下，已在游泳状态时按疾跑键，或未游泳时按 `上` + `疾跑` | 向视线方向冲刺（10 tick 推进时间）。若冲出水面则触发海豚跳——空中保持游泳姿态和身体旋转。 |

#### 特殊

| 状态 | 触发方式 | 行为 |
|---|---|---|
| **闪避 (Dodge)** | 按住方向键时双击疾跑键（可配置为单击）；装备喷气助推器后可在空中使用 | 向对应方向快速位移，期间有无敌帧（10 tick）。与水中推进共用冷却，最多可存储一层充能。 |
| **原版 (Original)** | 模组模式关闭（`Shift + M`） | 所有模组行为禁用，使用原版移动。也是无状态匹配时的回退状态。 |

### 装备

**喷气助推器** — 装备于 Curios 腰带栏位。效果：
- 通过属性修饰器提升移动速度、跳跃高度和上台阶高度。
- 墙跑不会下坠。
- 可在空中闪避。
- 所有摔落伤害减免 50%，等效摔落距离减少 12 格。

### 按键

| 按键 | 功能 |
|---|---|
| `C` | 降低重心（匍匐、滑铲、准备受身、翻入） |
| `Shift + M` | 切换机动模式 开/关 |
| `Shift + N` | 切换屏幕按键提示 开/关 |

多数主动动作会在屏幕显示当前可用的按键提示，引用玩家绑定的原版键位（`W`、`A`、`S`、`D`、`空格`、`Shift`、`Ctrl`）。

### 配置

所有功能开关在 `ServerConfig` 和 `ClientConfig` 中均有对应项，多数动作需要两处同时启用：

- `ServerConfig` 控制服务端强制启用。关闭后所有玩家均无法使用该动作。
- `ClientConfig` 允许单个玩家在本地关闭特定动作。

配置值通过 NeoForge 的 `ModConfigSpec` 系统读取。

## 架构

- **状态机**：每个玩家拥有一个 `MovementStateMachine`，每客户端 tick 按优先级评估 17 个状态转换。状态变化通过轻量数据包同步至服务端。
- **效果系统**：物理数值（加速度、阻力、方块阻力、速度上限）通过可组合的效果修改，类型包括 `REPLACE`、`BASE_MULTIPLIER`、`LOCAL_VALUE`、`COMPOSE`、`MULTIPLIER`，按优先级顺序生效。
- **物理注入**：4 个 Mixin 类分别修改 `Entity`（上下台阶/坡度检测）、`LivingEntity`（空/水移动、跳跃增强、身体旋转、梯子加速）、`GameRenderer`（摄像头倾斜/FOV）和 `AvatarRenderer`（非原版状态的游泳姿态渲染）。
- **动画系统**：PlayerAnimationLib 驱动基岩版格式的骨骼动画，MoLang 表达式绑定到 `PlayerMovementContext` 导出的每 tick 移动数据。
