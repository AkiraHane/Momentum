# 动量

[English Version](README.md)

为 Minecraft 增加滑铲、墙跑、挂墙、蹬墙跳和闪避等跑酷动作，支持 Fabric 和 NeoForge。

## 安装

当前分支面向 Minecraft `26.1.2`，使用 Fabric Loader `0.19.2` 或 NeoForge `26.1.2.64-beta`。

将对应加载器的模组和必需依赖放入 `mods/`：

| 加载器            | 依赖                                       | 版本                   | 说明                     |
|-------------------|--------------------------------------------|------------------------|--------------------------|
| Fabric / NeoForge | Player Animation Library（对应加载器版本） | `1.2.8+mc.26.1`        | 必需                     |
| Fabric            | Fabric API                                 | `0.149.1+26.1.2`       | 必需                     |
| NeoForge          | Curios                                     | `15.0.0-beta.2+26.1.2` | 可选，提供助推器腰带槽位 |
| Fabric            | Trinkets Updated                           | `4.0.1+26.1`           | 可选，提供助推器腰带槽位 |

## 操作

以下使用默认键位。前进、跳跃、潜行和疾跑沿用游戏中的按键绑定，屏幕提示会显示当前可用动作。

| 按键        | 功能         |
|-------------|--------------|
| `C`         | 降低重心     |
| `Shift + M` | 开关机动模式 |
| `Shift + N` | 开关按键提示 |
| 未绑定      | 墙面交互     |

Fabric 可单独设置功能组合键，默认左 Shift，与 `M`、`N` 配合使用；取消绑定后可单按 `M`、`N` 切换。

如果绑定了墙面交互键，必须按住才能跑墙、爬墙、滑墙和挂墙，松开退出；未绑定时自动与墙面交互。

| 动作     | 操作与效果                                                                         |
|----------|------------------------------------------------------------------------------------|
| 匍匐     | 地面按住 `C`，可通过 1 格高通道                                                    |
| 滑铲     | 地面达到一定速度后按住 `C`，降低重心滑行，可通过 1 格高通道                        |
| 蓄力跳   | 地面松开潜行键后立即跳跃，提高跳跃高度                                             |
| 受身     | 下落时按住 `C`，落地翻滚并减免摔落伤害                                             |
| 爬墙     | 贴墙向墙移动并按住跳跃，可以沿着墙面向上攀爬一定距离                               |
| 滑墙     | 下落时面向并贴近墙壁，向墙移动或按住跳跃，减缓下落                                 |
| 挂墙     | 下落时靠近可抓取边缘自动悬挂；按潜行键脱离                                         |
| 蹬墙跳   | 空中贴墙时向墙外移动并按跳跃；墙跑时按跳跃蹬离墙面。抬头、低头会影响跳跃的上下方向 |
| 墙跑     | 空中沿墙达到一定速度后按住前进＋跳跃；进入后按住前进维持                           |
| 翻越     | 抓住边缘时按跳跃，登上平台                                                         |
| 翻入     | 面对低矮通道，站立时按前进＋`C`，挂墙时按 `C`＋跳跃，可钻入1格高通道               |
| 游泳     | 水中按住前进＋`C` 进入游泳                                                         |
| 水中推进 | 水下按下疾跑键，向视线方向推进；未游泳时需同时按住前进                             |
| 闪避     | 按住疾跑键（默认 `Ctrl`）并双击方向键，向对应方向闪避                              |

闪避与水中推进共用冷却。闪避触发方式可在客户端配置中调整。

## 喷气助推器

可装备在护腿槽；安装 Curios（NeoForge）或 Trinkets Updated（Fabric）后也可使用腰带槽。助推器提高移动速度、跳跃高度和上台阶高度，支持空中闪避，减缓墙跑下坠并降低摔落伤害。

## 配置

- 服务端配置：动作开关、移动参数、冷却和助推器使用条件。
- 客户端配置：动作开关、闪避触发方式、相机效果和按键提示。

多数动作需要服务端与客户端对应开关同时开启。

## 构建

需要 JDK 25。

| 命令                            | 用途                                                           |
|---------------------------------|----------------------------------------------------------------|
| `./gradlew build`               | 构建 Fabric 和 NeoForge 模组，产物位于对应模块的 `build/libs/` |
| `./gradlew :fabric:runClient`   | 启动 Fabric 开发客户端                                         |
| `./gradlew :neoforge:runClient` | 启动 NeoForge 开发客户端                                       |
| `./gradlew :neoforge:runData`   | 运行 NeoForge 数据生成                                         |

Windows PowerShell 使用 `.\gradlew.bat` 替代 `./gradlew`。
