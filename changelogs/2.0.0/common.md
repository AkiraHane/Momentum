## English

### Added

- Fabric support: Added a Fabric version with maneuver actions, animations, and key hints. Install Trinkets Updated to equip the Jet Booster in a belt slot.
- Function Modifier (Fabric): The modifier used to toggle maneuver mode and key hints can be rebound separately. It defaults to Left Shift. Unbind it to use `M` and `N` alone.

### Changes

- Consecutive wall kicks: Reduced the default wait between wall kicks that grant extra speed from 1 second to 0.5 seconds, making it easier to build speed with repeated kicks.

## 中文

### 新增

- Fabric 支持：新增 Fabric 版本，可使用机动动作、动画和按键提示；安装 Trinkets Updated 后，可将喷气助推器装备在腰带槽。
- 功能组合键（Fabric）：切换机动模式和按键提示时使用的组合键可以单独改绑，默认是左 Shift。取消绑定后，可单独按 `M`、`N` 切换。

### 调整

- 连续墙跳优化：墙跳获得额外加速的默认间隔由 1 秒缩短为 0.5 秒，更容易连续蹬墙提速。
